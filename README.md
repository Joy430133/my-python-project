# JKUAT University Information Management System

This repository contains a simple C++ object-oriented prototype for the JKUAT University Information Management System described in the project analysis and design documents.

Included work:
- `main.cpp`: an OOP-based console system for students, lecturers, and administrators
- Student portal and lecturer LMS menu flow
- Registration and result synchronization between student records and LMS grading

The project follows the phases discussed in the coursework:
- system analysis
- system design
- object-oriented programming implementation

Run with a C++ compiler, for example:

```bash
g++ main.cpp -o jkuat_ims
./jkuat_ims
```
